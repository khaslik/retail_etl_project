# ETL-проект: онлайн-ретейл

## Исходные данные
Датасет UCI Online Retail II (транзакции интернет-магазина).

## Что сделано
- Очистка пропусков и некорректных значений
- Создание новых признаков: год, месяц, день недели, час
- Расчёт общей суммы заказа
- Загрузка в MySQL
- Аналитические запросы: выручка по странам, топ-товары

## Как запустить
1. Установить зависимости: `python pip install pandas mysql-connector`
2. Создать базу данных `retail_db`
3. Запустить `etl.py load_to_database.py`
4. Выполнить запросы из `db_queries.sql`
